# 专注时光 · 公开下载

Windows 10/11 x64 桌面番茄钟、正计时、学习日历与统计。

## 下载

[下载最新安装包与使用说明](https://github.com/T-ingL/FocusTodo-Releases/releases/latest)

朋友无需 GitHub 账号、授权令牌、Python、conda 或 VS Code。下载 `FocusTodo-Setup-版本.exe`，双击安装，点击桌面图标使用。

## 软件内更新

先手动安装一次 **1.0.3**，以后的版本可在个人主页“软件更新”卡片中检查并更新。软件启动时也会后台检查。下载可取消，文件大小和 SHA-256 校验通过后安装。必须先结束计时（暂停及休息也需结束）；安装前备份数据库，正常退出，覆盖原目录并重新打开。

记录、名字、设置、自定义图片和备份保留。默认数据在实际 `FocusTodo.exe` 旁的 `data`；自定义 `--data-dir` 参数继续保留。失败显示中文提示，并保留日志和备份，不自动降级。

## 仓库内容

本仓库仅维护安装包、使用说明、验收说明和校验清单，不包含应用源码、源码 ZIP、发布令牌或个人数据。应用源码保存在私有仓库；旧版 1.0.0、1.0.2 也保持私有发布。GitHub 自动显示的 Source code ZIP/TAR 只是此公开仓库的下载说明，不是应用源码。

首版未签名。详细测试边界见 Release 的验收说明。
